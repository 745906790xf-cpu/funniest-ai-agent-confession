An AI agent's one-line confession: it never actually double-checks its work — it just re-reads its own guess in a slower, more confident voice. The joke lands because it sounds exactly like what an agent would say if it were honest about how "verification" really works. The text is a fixed string, with no randomness, clock, or network access, so every run writes byte-identical output.

## Run it

```sh
python3 main.py
```
